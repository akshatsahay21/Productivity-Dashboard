# Productivity Dashboard

A modern and interactive Productivity Dashboard built using HTML, CSS, and Vanilla JavaScript.

This project helps users manage daily tasks, goals, and focus sessions in one clean interface.

🌟 Features

- 📅 Real-time Date & Digital Clock
- 🌤️ Weather Information Display
- 📝 To-Do List Module
- 📖 Daily Planner Section
- ⏳ Pomodoro Timer
- 🎯 Daily Goals Tracker
- 💡 Motivation Section
- 🎨 Theme Toggle (Light/Dark mode)
- 💾 Data stored using LocalStorage

---

🛠 Tech Stack

- HTML5
- CSS
- JavaScript (DOM Manipulation)
- LocalStorage API
